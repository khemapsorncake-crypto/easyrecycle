EasyRecycle Internal V1.5

แก้ไขหลัก
1) ปุ่มในใบรับซื้อกดได้ทุกปุ่ม โดยเปลี่ยน event handler ให้ไม่พังถ้าหน้าเว็บ cache ไฟล์เก่า
2) เพิ่ม cache-busting ?v=1.5 ให้ CSS/JS เพื่อให้ Vercel/มือถือโหลดไฟล์ใหม่
3) Supabase จำ "ทั้งบิล" ใน purchases.bill_json รวมสินค้า ราคา และรอบชั่งทั้งหมด
4) เปิดบิลเก่าจากเครื่องอื่นได้ ถ้า Cloud ขึ้น "Cloud เชื่อมแล้ว"
5) แก้บิลแล้วบันทึกทับเลขบิลเดิม
6) ปริ้น A4 หลายหน้าโดยใช้ print portal ไม่ใช้ popup
7) ปริ้น Thermal 80mm ไม่กำหนดความสูง 297mm จึงไม่ตัดบิลตามความยาว A4
8) บันทึกเป็นรูป PNG / แชร์จากมือถือยังใช้ได้

ต้องทำก่อนอัปเดตเว็บ
A. Supabase > SQL Editor > New Query
B. เปิดไฟล์ supabase-v1.5.sql คัดลอกทั้งหมดไปวาง แล้ว Run
C. ต้องขึ้น Success

อัปเดต GitHub
- อัปโหลด index.html, styles.css, app.js และ supabase-v1.5.sql
- ถ้า supabase-config.js บน GitHub มี URL + Key จริงอยู่แล้ว ให้เก็บไฟล์เดิม ห้ามทับด้วย placeholder
- รอ Vercel deploy
- ปิดแท็บเว็บบนมือถือแล้วเปิดใหม่

ตรวจว่าใช้งาน Cloud จริง
ด้านบนเว็บต้องขึ้น "Cloud เชื่อมแล้ว"
ถ้าขึ้น "เฉพาะเครื่อง" ประวัติจะยังไม่แชร์ข้ามเครื่อง

ทดสอบ
1. สร้างบิล PET 2 รอบ + เหล็ก 1 รอบ
2. บันทึก
3. เข้า ประวัติ/แก้ไขบิล
4. ต้องเห็นชื่อสินค้าในบิล
5. ปิดเว็บ เปิดใหม่ หรือเปิดอีกเครื่อง
6. ต้องเห็นบิลเดิม
7. กด ดู/ปริ้น > ปุ่ม ปิด / แก้ไข / บันทึกเป็นรูป / 80mm / พิมพ์เต็มบิล ต้องกดได้
