EasyRecycle Internal

ระบบรับซื้อภายในร้าน ไม่ต้อง Login

ฟังก์ชัน:
- เพิ่มรายการสินค้าและแก้ราคาได้
- สินค้าหนึ่งรายการชั่งได้หลายรอบ
- รวมจำนวนรอบ น้ำหนัก และยอดเงินอัตโนมัติ
- ออกใบรับซื้อและพิมพ์/PDF
- ประวัติการรับซื้อและสรุปยอด
- Export CSV และสำรองข้อมูล JSON
- ใช้งานบนมือถือได้

วิธีอัปเดตเว็บเดิมบน GitHub/Vercel:
1. แตกไฟล์ ZIP
2. เข้า GitHub repository easyrecycle
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ทับไฟล์เดิม
4. กด Commit changes
5. Vercel จะอัปเดตเว็บเดิมให้อัตโนมัติ

หมายเหตุ:
ข้อมูลเก็บในเบราว์เซอร์ของอุปกรณ์นั้น กรุณากดสำรองข้อมูลเป็นระยะ
