EasyRecycle Internal V1.3

เพิ่มใหม่
- บิลที่บันทึกแล้วกด "แก้ไข" ได้
- แก้ชื่อผู้ขาย วันที่ วิธีชำระ รายการสินค้า ราคา และน้ำหนักแต่ละรอบได้
- บันทึกการแก้ไขทับบิลเลขเดิม
- เปิดบิลเก่าแล้วพิมพ์ใหม่ / บันทึก PDF ได้
- ปุ่ม "บันทึกเป็นรูป" สร้าง PNG ของใบรับซื้อ
- มือถือที่รองรับ Share จะเปิดเมนูแชร์รูปให้ทันที
- รองรับ Supabase และ LocalStorage
- ชั่งหลายรอบเหมือนเดิม

วิธีอัปเดต
1) แตก ZIP
2) ถ้าคุณมี supabase-config.js ที่ใส่ URL/Key จริงแล้ว:
   ให้คัดลอกค่าจริงมาใส่ใน supabase-config.js ของ V1.3 ก่อนอัปโหลด
3) อัปโหลด index.html, styles.css, app.js และ supabase-config.js ขึ้น GitHub ทับของเดิม
4) Vercel จะ deploy อัตโนมัติ
5) เปิดเว็บใหม่และรีเฟรช

Supabase
- ถ้ายังไม่ได้สร้างตารางทั้งหมด ให้เปิด supabase-v1.3.sql ใน SQL Editor แล้วกด Run
- ใช้ Publishable key / anon public key เท่านั้น ห้ามใส่ service_role / secret key ในหน้าเว็บ

วิธีใช้งานการแก้ไขบิล
ประวัติ/แก้ไขบิล > กด "แก้ไข" > แก้ข้อมูล > กด "บันทึกการแก้ไขบิล"
ระบบจะใช้เลขบิลเดิม

วิธีบันทึกรูป
เปิดบิล > กด "บันทึกเป็นรูป"
บนมือถือบางรุ่นจะขึ้น Share Sheet ให้เลือก Save Image / LINE / แอปอื่น


V1.4 - แก้ปัญหาพิมพ์บิลยาวไม่ครบ
- เปลี่ยนการพิมพ์ให้เปิดหน้า Print แยกจาก popup เดิม
- "พิมพ์เต็มบิล / PDF" ใช้ A4 และแบ่งหน้า 2, 3, 4... อัตโนมัติ
- "พิมพ์ 80mm" สำหรับเครื่องพิมพ์ Thermal
- รายการสินค้าไม่ถูกแบ่งครึ่งหน้าเท่าที่เบราว์เซอร์รองรับ
- บันทึกเป็นรูป PNG และแก้ไขบิลยังใช้ได้เหมือนเดิม

แนะนำ:
- ถ้าบิลยาวมาก ใช้ "พิมพ์เต็มบิล / PDF" จะครบที่สุด
- ถ้าใช้เครื่อง Thermal 80mm ให้เลือก Paper Size = 80mm ใน Printer Settings
