EasyRecycle POS Pro — ระบบรับซื้อแบบชั่งหลายรอบ

ฟังก์ชันสำคัญ
- เลือกรายการสิ่งของจากข้อมูลต้นแบบใน Excel
- สินค้าหนึ่งรายการเพิ่มรอบชั่งได้ไม่จำกัด
- แสดงรอบที่ 1, 2, 3... และแก้ไข/ลบรอบได้
- รวมจำนวนรอบ น้ำหนักรวม และคำนวณน้ำหนักรวม × ราคาอัตโนมัติ
- ใบรับซื้อแสดงรายละเอียดน้ำหนักทุกรอบ
- ประวัติแสดงจำนวนรายการ จำนวนรอบ และยอดเงิน
- Export CSV แยกข้อมูลทีละรอบเพื่อเปิดใน Excel
- ใช้งานบนมือถือและติดตั้งเป็น PWA ได้

วิธีเปิดทดลอง
1. เปิดโฟลเดอร์นี้ด้วย VS Code
2. คลิกขวา index.html > Open with Live Server
3. ห้ามเปิดแบบ file:// หากต้องการติดตั้ง PWA

หมายเหตุ
ข้อมูลเก็บใน Local Storage ของเบราว์เซอร์เครื่องนั้น ควรกด “สำรองข้อมูล” เป็นระยะ
